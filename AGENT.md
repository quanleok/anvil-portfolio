# Working on the public Anvil example

Start with README.md, apps/desktop/README.md, and docs/09-protected-server-split.md.

This repository demonstrates the desktop workspace, browser interfaces, provider integrations, and a generic assistant. Keep private production methods, operational notes, credentials, and user project records outside this copy.

Preserve existing user changes. Keep the shared API contracts and file permissions intact. Run the checks appropriate to your changes before committing. Use placeholder configuration and synthetic data for tests; live services require the developer's own setup.
